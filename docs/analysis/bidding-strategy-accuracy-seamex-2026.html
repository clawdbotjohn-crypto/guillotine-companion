Appendix B — Methods, formulas, and scoreability

  • Signed error: prediction − explicit submitted amount. Positive means overprediction.

Appendix F — Glossary

Canonical claim
One classified manager-target competitive path after duplicate and contingency handling.
Explicit non-bid
No submitted claim matched for that manager-target opportunity; it has no dollar amount.
Observed minimum proxy
One dollar above the highest observed clearing-eligible losing bid, where identifiable; not a true reservation price.
Token
A zero/near-zero claim retained separately from serious bidding.
Top credible / top all
Pre-waiver prediction bands retained by the exact audit; top all includes all modeled manager estimates.
Directional
A descriptive signal worth monitoring, not a validated reusable effect.
